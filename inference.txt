### The Inference Commands

First, set up some bash variables so you don't have to type the long paths every time:

```bash
# Define your paths (Update these to your college server paths on Monday!)
BASE_MODEL="/home/aashishbishow/moon/Moonbeam-MIDI-Foundation-Model/moonbeam_checkpoint/moonbeam_839M.pt"
LORA_DIR="/home/aashishbishow/moon/Moonbeam-MIDI-Foundation-Model/moonbeam_checkpoint/multi_task_lora/epoch_9" 
CONFIG="src/llama_recipes/configs/model_config_multi_task.json"
DICT="processed/ComMU/indexed_tokens_dict.json" # Path to your master dictionary
```
*(⚠️ **Important:** If your training stops early or you resume and it finishes at `epoch_4`, change `epoch_9` to `epoch_4` in the `LORA_DIR` variable!)*

#### 1. The "Hybrid Masterpiece" (TIES Merged)
This triggers the `heuristic_router` to blend all 3 adapters (50% CoMMU, 25% EMOPIA, 25% SLakh) using TIES merging. It will generate a structurally sound, emotionally dynamic, multi-instrumental track.
```bash
python recipes/inference/custom_music_generation/multi_task_generate.py \
  --ckpt_dir $BASE_MODEL \
  --lora_dir $LORA_DIR \
  --task_type hybrid \
  --model_config_path $CONFIG \
  --additional_token_dict_path $DICT \
  --output_midi hybrid_masterpiece.mid \
  --max_gen_len 1024 \
  --temperature 0.8 \
  --top_p 0.9
```

#### 2. Pure EMOPIA (Emotional Focus)
This triggers the router to heavily weight the EMOPIA adapter (80% EMOPIA, 20% CoMMU for basic rhythm).
```bash
python recipes/inference/custom_music_generation/multi_task_generate.py \
  --ckpt_dir $BASE_MODEL \
  --lora_dir $LORA_DIR \
  --task_type emopia \
  --model_config_path $CONFIG \
  --additional_token_dict_path $DICT \
  --output_midi emotional_track.mid \
  --max_gen_len 1024 \
  --temperature 0.8
```

#### 3. Pure SLakh (Orchestral Focus)
This triggers the router to heavily weight the SLakh adapter (80% SLakh, 20% CoMMU).
```bash
python recipes/inference/custom_music_generation/multi_task_generate.py \
  --ckpt_dir $BASE_MODEL \
  --lora_dir $LORA_DIR \
  --task_type slakh \
  --model_config_path $CONFIG \
  --additional_token_dict_path $DICT \
  --output_midi orchestral_track.mid \
  --max_gen_len 1024 \
  --temperature 0.8
```

#### 4. Pure CoMMU (Baseline Structure)
This uses 100% CoMMU adapter. Great for comparing against the Hybrid model to hear exactly what the EMOPIA and SLakh adapters added!
```bash
python recipes/inference/custom_music_generation/multi_task_generate.py \
  --ckpt_dir $BASE_MODEL \
  --lora_dir $LORA_DIR \
  --task_type commu \
  --model_config_path $CONFIG \
  --additional_token_dict_path $DICT \
  --output_midi baseline_commu.mid \
  --max_gen_len 1024 \
  --temperature 0.8
```

### Method 2: The "Pro" Way (Create a Bash Script)
If you want to be super organized, you can save these commands into a single file on the college server called `generate_music.sh`. 

**Step 1:** Create the file using `nano`:
```bash
nano generate_music.sh
```

**Step 2:** Paste this exact code into the file:
```bash
#!/bin/bash

# --- UPDATE THESE PATHS FOR THE COLLEGE SERVER ---
BASE_MODEL="/path/to/college/server/moonbeam_839M.pt"
LORA_DIR="/path/to/college/server/multi_task_lora/epoch_9" 
CONFIG="src/llama_recipes/configs/model_config_multi_task.json"
DICT="processed/ComMU/indexed_tokens_dict.json"
# -------------------------------------------------

echo "Generating Hybrid Masterpiece..."
python recipes/inference/custom_music_generation/multi_task_generate.py \
  --ckpt_dir $BASE_MODEL --lora_dir $LORA_DIR --task_type hybrid \
  --model_config_path $CONFIG --additional_token_dict_path $DICT \
  --output_midi hybrid_masterpiece.mid --max_gen_len 1024

echo "Generating EMOPIA Emotional Track..."
python recipes/inference/custom_music_generation/multi_task_generate.py \
  --ckpt_dir $BASE_MODEL --lora_dir $LORA_DIR --task_type emopia \
  --model_config_path $CONFIG --additional_token_dict_path $DICT \
  --output_midi emotional_track.mid --max_gen_len 1024

echo "Generating SLakh Orchestral Track..."
python recipes/inference/custom_music_generation/multi_task_generate.py \
  --ckpt_dir $BASE_MODEL --lora_dir $LORA_DIR --task_type slakh \
  --model_config_path $CONFIG --additional_token_dict_path $DICT \
  --output_midi orchestral_track.mid --max_gen_len 1024

echo "All tracks generated successfully!"
```

**Step 3:** Save and exit (`Ctrl+O`, `Enter`, `Ctrl+X`).

**Step 4:** Make the file executable:
```bash
chmod +x generate_music.sh
```

**Step 5:** On Monday afternoon, when training is done, you just type **one single command** to generate all three songs back-to-back:
```bash
./generate_music.sh
```
